## My Projects

Here are a few projects I’m actively working on and excited to share.

   - **Agent Passport:** [github.com/0al-spec/agent-passport](https://github.com/0al-spec/agent-passport)
   - **Hypercode:** [github.com/0al-spec/Hypercode](https://github.com/0al-spec/Hypercode)

   - **Specification-Implementation Balance Metrics:** [github.com/0al-spec/Metrics](https://github.com/0al-spec/Metrics)

2. [XcodeMCPWrapper](https://github.com/SoundBlaster/XcodeMCPWrapper)  
   An **MCP proxy** that makes the MCP support in **Xcode 26.3** compatible with **Cursor** and other clients that strictly follow the MCP specification.

3. [Flow — Agentic Workflow](https://github.com/SoundBlaster/Flow)  
   A practical framework for building **repeatable, agent-driven contribution workflows** with clear steps, inputs and outputs, and quality gates.

4. [SpecificationCore](https://github.com/SoundBlaster/SpecificationCore)  
   A Swift framework that implements the **Specification Pattern** using modern Swift features such as **property wrappers**, **macros**, and **async/await**.

5. [SpecificationKit](https://github.com/SoundBlaster/SpecificationKit)  
   Platform-focused integrations and product-level tools built around **SpecificationCore**.

6. [SpecificationConfig](https://github.com/SoundBlaster/SpecificationConfig)  
   **Specifications for Swift configuration** — validation and composition for configuration models.

7. [ScreenKit](https://github.com/SoundBlaster/ScreenKit)  
   A modern, functional API for UIKit screens without subclassing `UIViewController`.

8. [Patchwork](https://github.com/SoundBlaster/Patchwork)  
   A seamless path for migrating legacy UIKit content to SwiftUI.

9. [ISOInspector](https://github.com/SoundBlaster/ISOInspector)  
   A complex monorepo combining a cross-platform **ISO BMFF parser** with a **SwiftUI app**—MP4 boxes, tracks, atoms, and all the fun stuff.

10. [docc2context](https://github.com/SoundBlaster/docc2context)  
    A **DocC-to-Markdown converter** for **LLM-readable documentation**, with a web service in progress.
